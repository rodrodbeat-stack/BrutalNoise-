# BRUTAL NOISE — Independent Audio System

**888 DIGITAL FACTORY / Audio workstation + underground community**

Responsive browser-first prototype.

## Included
- Industrial control-room interface for desktop, tablet and mobile.
- Local audio import, playlist, playback, seek and volume.
- 16-step rhythm sequencer with four synthesized voices and BPM control.
- Local community composer and feed preview.

## Enable GitHub Pages
Repository **Settings → Pages → Deploy from a branch → main → /(root)**.

## Structure
- `index.html` — application structure
- `css/style.css` — responsive visual system
- `js/app.js` — audio player, sequencer and local community

No backend is connected yet. Imported audio and posts remain in the current browser session. Supabase integration comes after validating the visual direction.
